Sign in

Your projects are saved straight into your GitHub repository. Sign in with a GitHub access token that can edit this repo — it stays only in this browser.

How do I get a token?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → choose your portfolio repo.
  3. Permissions → Repository → Contents: Read and write.
  4. Generate, copy the token and paste it above.
